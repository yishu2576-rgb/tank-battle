# 坦克大战 · Tank Battle

一个用纯 HTML + CSS + JavaScript（Canvas）实现的经典《坦克大战》网页小游戏，无需任何依赖，双击打开即可游玩。

## ✨ 特性

- 🎮 经典玩法：驾驶坦克，消灭敌军，守住基地（鹰旗）
- 🧱 可破坏的砖墙、不可破坏的钢墙、水域、草丛等地形
- 🤖 多种敌军坦克：普通、快速、火力、装甲（4 血）
- 🎁 道具系统：护盾、加命、火力强化（双发/速射）、炸弹
- 🔫 子弹对撞抵消、连续关卡、难度递增
- 🔊 纯 Web Audio 音效（可静音）
- 📱 移动端触屏按键支持
- 💾 本地保存最高分

## 🕹️ 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| P / Esc | 暂停 |
| M | 静音 |

## ▶️ 运行

直接用浏览器打开 `index.html` 即可；或启动一个本地服务器：

```bash
# 例如
python -m http.server 8080
```

然后访问 http://localhost:8080
